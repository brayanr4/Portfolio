# Brayan Rahul Biju · Portfolio

Personal portfolio of Brayan Rahul Biju, Software Engineering (Honours) graduate from Flinders University.

It's a single self-contained page (`index.html`) with no build step: HTML, CSS and vanilla JavaScript, plus Google Fonts.

## Features

- Interactive, draggable force-directed graph of skills, projects and experience (canvas)
- Honours research section with an animated cyber security knowledge graph schema
- Light and dark themes that follow the system setting, with a manual toggle
- Quick navigation palette (press `/` or `Ctrl/Cmd + K`)
- Responsive down to phone widths, and respects reduced-motion preferences

## Run locally

Open `index.html` in a browser, or serve the folder:

```sh
python3 -m http.server 8000
```

## Deploy

Hosted with GitHub Pages from the `main` branch root. Any push to `main` redeploys the site.

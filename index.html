Cyber risk, as a graph.

Flinders University · Final year research

Cyber Security Knowledge Graph

Assets, threats, vulnerabilities, controls and incidents usually live in separate lists. This platform connects them in one graph, so you can follow an attack from a CAPEC pattern to a CVE to the asset it hits, and see which controls stand in the way.

  • Full stack: a React frontend, a Flask API and a Neo4j graph database.
  • REST endpoints to create, query and link every cyber entity and relationship.
  • Attack-path exploration and graph-based risk analysis for sharper security decisions.
  • Interactive visualisations that make risk and system dependencies visible at a glance.
